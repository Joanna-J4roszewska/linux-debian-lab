
# Linux / Debian Lab

Hands-on Linux administration practice in browser-based environments
(WebVM, Killercoda), documented step by step.

## Why browser-based?
My Active Directory homelab is temporarily on hold — I currently have
no access to my personal machine, so I'm focusing on Linux fundamentals
using online VMs in the meantime.

## Topics
- [ ] Basic commands & filesystem
- [ ] Users, groups, permissions
- [ ] Package management (apt)
- [ ] Processes & services
- [ ] Networking basics
- [ ] SSH & hardening
